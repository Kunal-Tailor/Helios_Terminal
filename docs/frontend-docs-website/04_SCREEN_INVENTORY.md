# 04 — Screen inventory (website)

Full section-by-section breakdown and image-gen prompts already live in
`Helios-Terminal-Marketing-Site-Design-Spec.md` (chat deliverable). This
file is the condensed reference version for implementation.

## Shared

- **Header** — sticky, logo + wordmark left, nav right (`Home ·
  Architecture · About · Team`), `Dashboard` as a separated filled button.
- **Footer** — one row: GitHub link, synopsis note, team credit line,
  institution line.

## Home (7 sections)

1. Header
2. Hero — tag, serif headline, subhead, two CTAs (Dashboard primary,
   Architecture secondary)
3. Problem teaser — two-column, prose + thin line-art fork diagram
4. Pipeline strip — six connected nodes, links to Architecture
5. Three pillars — decision-scoped / verified / self-correcting
6. Dashboard CTA band — full-width, deeper tone, dark gradient sliver at
   the bottom edge foreshadowing the Dashboard
7. Footer

## Architecture (7 sections)

1. Header
2. Intro — short headline + one paragraph, plain language
3. Pipeline flow diagram — six stage-cards, solid forward lines, dashed
   backward recalibration lines (visually distinct)
4. Recalibration explainer — 3-step sequence: sufficiency check → gap
   payload → bounded retry
5. Tech stack strip — plain-text/monospace labels, no logos
6. CTA — "See it in action" → Dashboard
7. Footer

## About (6 sections)

1. Header
2. Editorial hero — pure typographic, no imagery
3. Narrative — single centered column, ~680px, optional drop-cap
4. Who it's for — 3–4 short persona lines
5. Pull-quote — twofold contribution line, large serif italic
6. Synopsis card + Footer — bordered card (title, description, file
   type, download button), footer directly beneath

## Team (5 sections)

1. Header
2. Intro — short headline + one line of context
3. Team grid — 4 cards (name, role/contribution, initials avatar,
   icon links), wraps 2x2 on narrower widths
4. Contribution note — short text tying roles to the six-agent pipeline
5. Footer
